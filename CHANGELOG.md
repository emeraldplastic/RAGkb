# Changelog

All notable changes to RAGkb will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-01-01

### Added
- Document upload and processing (PDF, TXT, DOCX)
- Vector embeddings with ChromaDB for semantic search
- Multi-provider LLM support (Google Gemini, OpenAI, Anthropic)
- Chat interface for querying uploaded documents
- JWT-based authentication with user registration and login
- Rate limiting for API endpoints
- Request logging middleware
- SQLite database for document and conversation metadata
- Docker and Docker Compose support
- Vercel deployment configuration
- Frontend single-page application with chat, documents, and settings tabs
